# olist-business-intelligence

🚀 Olist 360° Business Intelligence Solution: จากข้อมูลดิบสู่กลยุทธ์ขับเคลื่อนธุรกิจ
โปรเจกต์นี้เป็นการสร้างระบบวิเคราะห์ข้อมูลธุรกิจแบบครบวงจร (End-to-end) สำหรับแพลตฟอร์ม E-commerce (Olist) โดยการเปลี่ยนข้อมูลธุรกรรมมหาศาลให้กลายเป็น Dashboard อัจฉริยะที่ช่วยในการตัดสินใจผ่าน 3 มุมมองหลัก:

🌟 องค์ประกอบสำคัญของโปรเจกต์
Project 1: เจาะลึกสุขภาพธุรกิจ (Sales & Operations): วิเคราะห์ภาพรวมยอดขายย้อนหลัง, รูปแบบการชำระเงินที่ลูกค้าชอบ, และประสิทธิภาพการขนส่ง (Logistics) เพื่อระบุคอขวดในกระบวนการส่งสินค้าแยกตามหมวดหมู่

Project 2: มองทะลุอนาคต (Sales Forecasting): พัฒนาโมเดลพยากรณ์ยอดขายล่วงหน้า 6 เดือนด้วย AI (Facebook Prophet) เพื่อช่วยให้ธุรกิจวางแผนงบประมาณและบริหารสต็อกสินค้าได้อย่างแม่นยำ พร้อมแสดงช่วงความเชื่อมั่น (Confidence Interval)

Project 3: เข้าใจหัวใจลูกค้า (Customer Strategic Insights): ใช้เทคนิค RFM Analysis เพื่อจัดกลุ่มลูกค้ากว่า 90,000 รายตามพฤติกรรมจริง ทำให้สามารถระบุกลุ่ม Champions ที่เป็นหัวใจหลัก และกลุ่ม Lost ที่ต้องเร่งทำแคมเปญดึงกลับมา (Win-back Campaign)

🛠️ เครื่องมือที่ใช้ (Tech Stack)
การจัดการข้อมูล: Python (Pandas, Numpy)

โมเดลพยากรณ์: Facebook Prophet (Time-series Forecasting)

การแสดงผลข้อมูล: Plotly Express, Streamlit

การออนไลน์ระบบ: Streamlit Cloud
